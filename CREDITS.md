## claude-code-proxy

The OpenAI connection is powered by [`raine/claude-code-proxy`](https://github.com/raine/claude-code-proxy).

Special thanks to:

- [Raine (`@raine`)](https://github.com/raine), creator and primary maintainer of `claude-code-proxy`
- every person in the upstream [contributor graph](https://github.com/raine/claude-code-proxy/graphs/contributors)

The proxy handles:

- Codex OAuth
- the local Anthropic-compatible address
- request and response conversion
- streaming
- tool calls
- reasoning effort
- model routing
- service packaging

Please star and support the upstream repository. Report a proxy problem there when it also happens without Airlock.
